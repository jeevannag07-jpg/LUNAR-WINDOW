# LUNAR WINDOW

### Lunar Mission Planning & Site Evaluation Platform

**Mission:** Transform lunar terrain and astronomical data into clear, time-aware operational insights.

LUNAR WINDOW helps users evaluate lunar locations based on solar visibility, Earth visibility, terrain constraints, and mission timing.

## Core Workflow

BUILD → ANALYZE → EVALUATE → COMPARE → DECIDE

## Technology Stack

- Frontend: React + TypeScript
- Backend: Python + FastAPI
- Scientific Computing: NumPy
- Astronomy Data: NASA JPL Horizons
- Terrain Data: Lunar Orbiter Laser Altimeter (LOLA)
